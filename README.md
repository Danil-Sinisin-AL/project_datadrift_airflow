1. Общий обзор системы
Система представляет собой полностью автоматизированный пайплайн MLOps, который включает:

Мониторинг дрейфа данных (PSI-метрика)

Автоматическое переобучение моделей при обнаружении дрейфа

A/B тестирование новых моделей

Автоматическое промоушн моделей в продакшн при улучшении метрик

API для инференса с поддержкой A/B тестирования и логированием

2. Детальное описание компонентов
2.1. Мониторинг дрейфа (Drift Detection)
Метрика: Population Stability Index (PSI)

Порог срабатывания: PSI > 0.2

Особенности:

Используется обучающая выборка как референсное распределение

Автоматическое определение бинов через процентили

Smoothing для предотвращения деления на ноль

Реакция: При превышении порога запускается переобучение

2.2. AutoML с PyCaret
Алгоритмы в сравнении: Logistic Regression, Random Forest, LightGBM, CatBoost, Gradient Boosting, Decision Tree

Критерий отбора: F1-Score

Конфигурация:

Cross-validation: 5 фолдов

Разделение данных: 80/20

Мультиклассовая классификация с weighted averaging

Результаты: Автоматическое сохранение лучшей модели и метаданных

2.3. Управление моделями в MLflow
Реестр моделей: Версионирование всех артефактов

Стадии жизненного цикла:

Staging: Новая модель после обучения

Production: Продакшн-версия

Archived: Предыдущие версии

Метаданные: Все обучение логируется с параметрами и метриками

2.4. A/B тестирование
Метрики сравнения:

Accuracy, Precision, Recall, F1-Score, ROC-AUC

Weighted averaging для мультиклассовой классификации

Процесс:

Загрузка Production и Staging моделей

Прогон на тестовых данных

Сравнение метрик

Автоматический промоушн при улучшении метрик

Критерий промоушна: Улучшение по всем ключевым метрикам

2.5. Flask API с логированием
Эндпоинты:

/predict: Основной endpoint для инференса

/ab_test: Ручное запуск A/B теста

/metrics: Просмотр метрик моделей

Логирование:

Все запросы и ответы

Время выполнения

Версия модели

Результаты предсказаний

A/B роутинг: Поддержка процентного распределения трафика
